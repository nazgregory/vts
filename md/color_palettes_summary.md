# 색상 팔레트 요약

## 개요
이 문서는 데이터 시각화 대시보드에서 사용되는 색상 팔레트들과 그 활용 방법을 설명합니다.

## 색상 팔레트 시스템

### 1. 시스템 개요
- **목적**: 차트 유형과 데이터 특성에 맞는 최적의 색상 조합 제공
- **구성**: 기본 색상, 전문 색상, 카테고리별 색상으로 분류
- **특징**: 접근성, 가독성, 시각적 효과를 고려한 색상 설계

### 2. 색상 선택 기준
- **대비**: 배경과의 충분한 대비로 가독성 확보
- **일관성**: 동일한 데이터 타입에 일관된 색상 적용
- **접근성**: 색맹 사용자를 고려한 색상 조합
- **감정**: 데이터의 성격에 맞는 색상 심리학 적용

## 기본 색상 팔레트

### 1. Primary Colors
- **용도**: 주요 데이터 시리즈, 핵심 지표
- **색상**: `["#0088FE", "#00C49F", "#FFBB28", "#FF8042", "#8884d8", "#82ca9d"]`
- **특징**: 
  - 파란색 계열: 신뢰성, 안정성
  - 초록색 계열: 성장, 긍정
  - 노란색 계열: 주의, 경고
  - 빨간색 계열: 중요, 긴급
  - 보라색 계열: 고급, 프리미엄

### 2. Secondary Colors
- **용도**: 보조 데이터 시리즈, 비교 대상
- **색상**: `["#FF6B6B", "#4ECDC4", "#45B7D1", "#96CEB4", "#FFEAA7", "#DDA0DD"]`
- **특징**: 
  - Primary 색상과 조화를 이루는 보조 색상
  - 대비가 적절하여 함께 사용 시 가독성 향상
  - 다양한 톤으로 선택의 폭 확대

### 3. Pastel Colors
- **용도**: 부드러운 느낌의 차트, 배경 요소
- **색상**: `["#FFB3BA", "#BAFFC9", "#BAE1FF", "#FFFFBA", "#FFB3F7", "#B3F7FF"]`
- **특징**: 
  - 부드럽고 편안한 느낌
  - 배경과의 조화가 좋음
  - 여성, 어린이 대상 데이터에 적합

## 히트맵 전용 색상

### 1. 과학적 색상 팔레트

#### Plasma
- **색상**: `["#0d0887", "#7e03a8", "#cc4778", "#f89441", "#f0f921"]`
- **용도**: 과학적 데이터, 연구 결과
- **특징**: 파란색에서 노란색으로의 부드러운 전환
- **적합 데이터**: 온도, 압력, 밀도 등 물리적 데이터

#### Inferno
- **색상**: `["#000004", "#1b0c41", "#4a0c6b", "#781c6d", "#a52c60", "#cf4446", "#e76d5a", "#f7b799", "#fde725"]`
- **용도**: 고온 데이터, 극값 표현
- **특징**: 검은색에서 노란색으로의 극적인 전환
- **적합 데이터**: 화재, 폭발, 고온 현상

#### Magma
- **색상**: `["#000004", "#180f3e", "#440f76", "#721f81", "#9e2f7f", "#cb3e71", "#e95c5c", "#f78357", "#fbb43f", "#fde725"]`
- **용도**: 지질학적 데이터, 지하 현상
- **특징**: 검은색에서 노란색으로의 단계적 전환
- **적합 데이터**: 지진, 화산, 지하수

#### Viridis
- **색상**: `["#440154", "#482878", "#3e4989", "#31688e", "#26828e", "#1f9e89", "#35b779", "#6ece58", "#b5de2b", "#fde725"]`
- **용도**: 범용 데이터, 색맹 사용자 고려
- **특징**: 파란색에서 노란색으로의 균등한 전환
- **적합 데이터**: 모든 종류의 수치 데이터

### 2. 전문 색상 팔레트

#### ReBu (Red-Blue)
- **색상**: `["#67001f", "#b2182b", "#d6604d", "#f4a582", "#fddbc7", "#f7f7f7", "#d1e5f0", "#92c5de", "#4393c3", "#2166ac", "#053061"]`
- **용도**: 양극값을 나타내는 데이터
- **특징**: 빨간색(높음) → 흰색(중간) → 파란색(낮음)
- **적합 데이터**: 온도 변화, 수익/손실, 증가/감소

#### Blues
- **색상**: `["#f7fbff", "#deebf7", "#c6dbef", "#9ecae1", "#6baed6", "#4292c6", "#2171b5", "#08519c", "#08306b"]`
- **용도**: 단조 증가 데이터
- **특징**: 연한 파란색에서 진한 파란색으로의 전환
- **적합 데이터**: 인구 밀도, 고도, 깊이

#### Coolwarm
- **색상**: `["#3b4cc0", "#6877d1", "#8fa0e0", "#b3c7ed", "#d4e4f7", "#f7f7f7", "#fde0d9", "#fcc5c0", "#fa9fb5", "#f768a1", "#dd3497", "#ae017e", "#7a0177"]`
- **용도**: 양극값을 나타내는 데이터
- **특징**: 차가운 파란색 → 중성 흰색 → 따뜻한 빨간색
- **적합 데이터**: 온도, pH, 전기적 특성

#### Greens
- **색상**: `["#f7fcf5", "#e5f5e0", "#c7e9c0", "#a1d99b", "#74c476", "#41ab5d", "#238b45", "#006d2c", "#00441b"]`
- **용도**: 자연, 환경 관련 데이터
- **특징**: 연한 초록색에서 진한 초록색으로의 전환
- **적합 데이터**: 식물 분포, 환경 지표, 생태학적 데이터

#### Oranges
- **색상**: `["#fff7ec", "#fee8c8", "#fdd49e", "#fdbe85", "#fd8d3c", "#e6550d", "#d94801", "#a63603", "#7f2704"]`
- **용도**: 경고, 주의 관련 데이터
- **특징**: 연한 주황색에서 진한 주황색으로의 전환
- **적합 데이터**: 경고 수준, 위험도, 주의 지표

#### Reds
- **색상**: `["#fff5f0", "#fee0d2", "#fcbba1", "#fc9272", "#fb6a4a", "#ef3b2c", "#cb181d", "#a50f15", "#67000d"]`
- **용도**: 위험, 오류 관련 데이터
- **특징**: 연한 빨간색에서 진한 빨간색으로의 전환
- **적합 데이터**: 오류율, 위험도, 손실률

#### Purples
- **색상**: `["#fcfbfd", "#efedf5", "#dadaeb", "#bcbddc", "#9e9ac8", "#807dba", "#6a51a3", "#54278f", "#3f007d"]`
- **용도**: 고급, 프리미엄 관련 데이터
- **특징**: 연한 보라색에서 진한 보라색으로의 전환
- **적합 데이터**: 고급 제품, VIP 고객, 프리미엄 서비스

#### YlOrBr (Yellow-Orange-Brown)
- **색상**: `["#ffffe5", "#fff7bc", "#fee391", "#fec44f", "#fe9929", "#ec7014", "#cc4c02", "#993404", "#662506"]`
- **용도**: 지질학적, 토양 관련 데이터
- **특징**: 노란색에서 주황색, 갈색으로의 전환
- **적합 데이터**: 토양 성분, 광물 분포, 지질학적 특성

## 카테고리별 색상

### 1. 비교·추세 분석
- **색상**: `#3B82F6` (파란색)
- **용도**: 막대 그래프, 선형 그래프, 누적 막대 그래프
- **심리학**: 신뢰성, 안정성, 전문성
- **적합 데이터**: 매출 추이, 성과 비교, 시계열 데이터

### 2. 비율·구성 분석
- **색상**: `#10B981` (초록색)
- **용도**: 원형 차트, 도넛 차트, 선버스트 차트
- **심리학**: 성장, 균형, 조화
- **적합 데이터**: 시장 점유율, 예산 배분, 구성 비율

### 3. 분포·관계 분석
- **색상**: `#F59E0B` (노란색)
- **용도**: 산점도, 버블 차트, 히스토그램
- **심리학**: 주의, 분석, 지적 호기심
- **적합 데이터**: 상관관계, 데이터 분포, 패턴 분석

### 4. 특수 분석
- **색상**: `#8B5CF6` (보라색)
- **용도**: 레이더 차트, 게이지 차트, 워드클라우드
- **심리학**: 창의성, 혁신, 독창성
- **적합 데이터**: 능력 평가, KPI 모니터링, 텍스트 분석

### 5. 고급 분석
- **색상**: `#EF4444` (빨간색)
- **용도**: 파넬 차트, 타임라인 차트
- **심리학**: 중요성, 긴급성, 주목
- **적합 데이터**: 복합 분석, 프로젝트 관리, 고급 시각화

## 색상 사용 가이드

### 1. 차트 유형별 색상 선택

#### 막대 그래프
- **주요 시리즈**: Primary 색상 사용
- **비교 시리즈**: Secondary 색상 사용
- **배경**: Pastel 색상으로 부드러운 느낌

#### 선형 그래프
- **메인 라인**: Primary 색상 중 진한 색상
- **보조 라인**: Secondary 색상으로 구분
- **영역 채우기**: 투명도를 적용한 Primary 색상

#### 원형 차트
- **각 섹션**: Primary 색상으로 구분
- **중요도 순**: 진한 색상에서 연한 색상으로 배치
- **배경**: 흰색 또는 매우 연한 회색

#### 히트맵
- **데이터 특성에 따른 선택**:
  - 일반 데이터: Viridis
  - 양극값: ReBu, Coolwarm
  - 단조 증가: Blues
  - 자연/환경: Greens
  - 경고/주의: Oranges, Reds

### 2. 데이터 특성별 색상 선택

#### 양적 데이터
- **연속형**: 그라데이션 색상 (Blues, Greens)
- **이산형**: 구분이 명확한 색상 (Primary, Secondary)

#### 범주형 데이터
- **명목형**: 구분이 명확한 색상 (Primary)
- **순서형**: 명도나 채도가 순서를 나타내는 색상

#### 시계열 데이터
- **추세**: Primary 색상의 그라데이션
- **계절성**: Secondary 색상으로 구분
- **변동성**: Reds, Oranges로 강조

### 3. 접근성 고려사항

#### 색맹 사용자
- **빨강-초록 색맹**: Blues, YlOrBr 색상 팔레트 사용
- **파랑-노랑 색맹**: Reds, Greens 색상 팔레트 사용
- **보조 요소**: 패턴, 선 스타일, 텍스트 라벨 추가

#### 대비 강화
- **최소 대비**: 4.5:1 이상 유지
- **권장 대비**: 7:1 이상
- **강조 요소**: 3:1 이상의 대비로 구분

## 색상 커스터마이징

### 1. 사용자 정의 색상
- **색상 선택기**: HSL, RGB, HEX 값 입력
- **색상 저장**: 자주 사용하는 색상 조합 저장
- **색상 가져오기**: 외부 색상 팔레트 파일 업로드

### 2. 자동 색상 생성
- **색상 수**: 데이터 개수에 따른 자동 색상 생성
- **색상 조화**: 색상 이론에 따른 조화로운 색상 조합
- **접근성**: 자동으로 접근성을 고려한 색상 조정

### 3. 색상 테마
- **기본 테마**: Primary, Secondary, Pastel
- **전문 테마**: 히트맵 전용 색상 팔레트
- **사용자 테마**: 개인적으로 정의한 색상 조합

## 성능 최적화

### 1. 색상 렌더링
- **하드웨어 가속**: GPU를 활용한 빠른 색상 렌더링
- **색상 캐싱**: 자주 사용하는 색상 조합 메모리 저장
- **지연 로딩**: 필요할 때만 색상 팔레트 로드

### 2. 메모리 관리
- **색상 객체 재사용**: 동일한 색상 객체 공유
- **불필요한 색상 제거**: 사용하지 않는 색상 팔레트 정리
- **색상 압축**: 유사한 색상 그룹화
