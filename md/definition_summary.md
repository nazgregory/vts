# 프로젝트 정의 요약

## 개요
- **프로젝트명**: 데이터 시각화 대시보드
- **버전**: 1.0.0
- **최종 업데이트**: 2026-10-21
- **기술 스택**: React 18 + TypeScript + Vite + Plotly.js 2.27.0 + Leaflet + Tailwind CSS. 백엔드는 Express + Prisma + PostgreSQL
- **아키텍처**: 컴포넌트 기반 SPA. 차트는 브라우저에서 그리고, 사용 이력만 서버에 저장한다

## 핵심 개념

### 데이터 시각화
데이터를 그래프, 차트 등의 시각적 요소로 변환하여 정보를 직관적으로 전달하는 과정

### 차트 유형
데이터의 특성과 분석 목적에 따라 선택되는 시각화 방법

### 커스터마이징
사용자가 차트의 색상, 제목, 축 레이블, 범례 등을 수정할 수 있는 기능

## 차트 카테고리 (6개 분석 유형, 21종 차트)

### 1. 비교·추세 분석 (4종)
- **목적**: 데이터의 변화 추세와 항목 간 비교
- **차트**:
  - 선형 그래프: 데이터 변화 추세 확인용
  - 누적 영역 그래프: 합계 추세와 구성비 동시 표현
  - 막대 그래프: 항목 간 값 비교
  - 누적 막대 그래프: 시간별 누적 추세와 구성비 비교
- **사용 사례**: 매출 추이, 성과 비교, 시계열 분석, 예산 대비 실적

### 2. 비율·구성 분석 (4종)
- **목적**: 전체 대비 구성 요소의 비율을 표현
- **차트**:
  - 원형 차트: 전체 대비 항목 비율
  - 도넛 차트: 중앙 요약 정보가 있는 원형 차트
  - 선버스트 차트: 다층 구조 비율 시각화
  - 트리맵: 계층형 비율 시각화
- **사용 사례**: 시장 점유율, 예산 배분, 인구 구성, 매출 구성

### 3. 분포·관계 분석 (4종)
- **목적**: 데이터의 분포와 변수 간 관계를 분석
- **차트**:
  - 산점도: 변수 간 상관관계
  - 버블 차트: 3변수 비교(크기, 위치, 색상)
  - 히스토그램: 데이터 분포 확인
  - 박스플롯: 데이터 분포와 이상치 확인
- **사용 사례**: 상관관계 분석, 데이터 분포, 패턴 발견, 이상치 탐지

### 4. 특수 분석 (4종)
- **목적**: 특정 목적을 위한 전문화된 차트 유형
- **차트**:
  - 레이더 차트: 다차원 데이터 비교
  - 타임라인(공정표): 프로젝트 일정 및 공정표 관리
  - 게이지 차트: KPI, 목표 달성률
  - 워드클라우드: 텍스트 데이터 빈도 시각화
- **사용 사례**: 능력 평가, KPI 모니터링, 텍스트 분석, 프로젝트 관리

### 5. 고급 분석 (4종)
- **목적**: 복잡한 데이터 구조와 다차원 분석
- **차트**:
  - 히트맵: 값의 크기를 색으로 표현
  - 워터폴 차트: 증가·감소 요인별 변화 시각화
  - 콤보 차트: 서로 다른 유형 데이터 동시 비교
  - 파넬 차트: 여러 차트를 그리드로 배치
- **사용 사례**: 다변량 분석, 요인 분석, 복합 데이터 시각화, 대시보드 구성

### 6. 지도 위치 시각화 (1종)
- **목적**: 지리적 위치와 관련된 데이터를 지도상에 시각화
- **차트**:
  - 지도 시각화: 위도·경도 또는 주소로 지도에 마커를 표시
- **사용 사례**: 지역별 분석, 지점별 데이터, 지리적 분포, 위치 기반 서비스

## 데이터 형식

### 지원 형식
- **CSV**: UTF-8 인코딩으로 쉼표로 구분된 데이터 형식
- **Excel**: Microsoft Excel 파일 형식 (.xlsx)

### 데이터 구조
- 첫 번째 행은 헤더
- 그 다음부터 실제 데이터가 위치하는 구조

### 인코딩 지원
- UTF-8
- UTF-8 BOM

## 사용자 역할

### 일반 사용자
- 차트 생성, 커스터마이징, 샘플 데이터 다운로드 기능 사용
- 21가지 차트 유형 중 선택하여 데이터 시각화

## 주요 기능

### 실시간 커스터마이징
색상 팔레트, 범례 위치, 축 설정 등을 실시간으로 커스터마이징

### 샘플 데이터 다운로드
21가지 차트 유형별 샘플 데이터를 CSV와 XLSX로 제공

### 반응형 디자인
모바일과 데스크톱 환경에 최적화된 반응형 UI

## 기술적 특징

### 프론트엔드
- React 18.2.0 기반 컴포넌트 아키텍처
- TypeScript를 통한 타입 안전성
- Tailwind CSS를 활용한 모던한 UI

### 차트 렌더링
- Plotly.js 기반 고성능 차트 렌더링
- 21가지 차트 유형 지원
- 실시간 데이터 업데이트 및 애니메이션

### 데이터 처리
- CSV/Excel 파일 자동 파싱
- 다양한 데이터 형식 지원
- 에러 처리 및 유효성 검증

### 성능 최적화
- 컴포넌트 지연 로딩
- 메모리 효율적인 데이터 처리
- 반응형 차트 렌더링
