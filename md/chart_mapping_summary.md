# 차트 매핑 요약

## 개요
이 문서는 차트 유형별로 필요한 데이터 형태와 작성 예시를 정리합니다.

## 차트 분류 체계

### 1. 비교·추세 분석
데이터의 변화 추세와 항목 간 비교를 위한 차트 유형들입니다.

#### 선형 그래프
- **설명**: 데이터·변화 추세 확인용
- **적합 데이터**: 시계열 데이터, 연속형 수치 데이터
- **데이터 조건**: 
  - 열 수: 2개 이상
  - 데이터 타입: 날짜형/시간형 + 수치형
  - 행 수: 5개 이상 (추세 파악 가능)
- **사용 사례**: 매출 추이, 온도 변화, 주가 변동

#### 누적 영역 그래프
- **설명**: 합계 추세와 구성비 동시 표현
- **적합 데이터**: 구성 요소의 변화를 보여주는 데이터
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 시간형 + 여러 수치형 (누적)
  - 행 수: 5-20개
- **사용 사례**: 월별 매출 구성, 연도별 예산 배분

#### 막대 그래프
- **설명**: 항목 간 값 비교
- **적합 데이터**: 범주형 데이터, 이산형 수치 데이터
- **데이터 조건**: 
  - 열 수: 2-3개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 3-20개 (가독성 고려)
- **사용 사례**: 제품별 매출, 지역별 인구, 월별 방문자 수

#### 누적 막대 그래프
- **설명**: 시간별 누적 추세와 구성비 비교
- **적합 데이터**: 구성 요소의 변화를 보여주는 데이터
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 시간형 + 범주형 + 수치형
  - 행 수: 3-15개
- **사용 사례**: 월별 매출 구성 변화, 연도별 예산 배분 변화

### 2. 비율·구성 분석
전체 대비 구성 요소의 비율과 계층적 구조를 시각화하는 차트 유형들입니다.

#### 원형 차트
- **설명**: 전체 대비 항목 비율
- **적합 데이터**: 전체 대비 구성 비율
- **데이터 조건**:
  - 열 수: 2개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 3-8개 (가독성 고려)
- **사용 사례**: 시장 점유율, 예산 배분, 인구 구성

#### 도넛 차트
- **설명**: 중앙 요약 정보가 있는 원형 차트
- **적합 데이터**: 원형 차트와 유사하지만 중앙 공간 활용
- **데이터 조건**:
  - 열 수: 2개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 3-8개
- **사용 사례**: 진행률 표시, 목표 대비 달성률

#### 선버스트 차트
- **설명**: 다층 구조 비율 시각화
- **적합 데이터**: 계층적 구조의 비율 데이터
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 계층형 + 수치형
  - 행 수: 10-50개
- **사용 사례**: 파일 시스템 용량, 조직도, 제품 카테고리

#### 트리맵
- **설명**: 계층형 비율 시각화
- **적합 데이터**: 계층적 구조의 면적 기반 데이터
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 계층형 + 수치형
  - 행 수: 10-100개
- **사용 사례**: 포트폴리오 분석, 웹사이트 트래픽

### 3. 분포·관계 분석
데이터의 분포 특성과 변수 간의 관계를 분석하는 차트 유형들입니다.

#### 산점도
- **설명**: 변수 간 상관관계
- **적합 데이터**: 두 변수 간의 관계 분석
- **데이터 조건**:
  - 열 수: 2개
  - 데이터 타입: 수치형 + 수치형
  - 행 수: 20개 이상 (패턴 파악 가능)
- **사용 사례**: 키와 몸무게, 광고비와 매출

#### 버블 차트
- **설명**: 3변수 비교(크기, 위치, 색상)
- **적합 데이터**: 3차원 데이터 (X, Y, 크기)
- **데이터 조건**:
  - 열 수: 3개
  - 데이터 타입: 수치형 + 수치형 + 수치형
  - 행 수: 10-50개
- **사용 사례**: 국가별 GDP, 인구, 면적

#### 히스토그램
- **설명**: 데이터 분포 확인
- **적합 데이터**: 단일 변수의 분포 분석
- **데이터 조건**:
  - 열 수: 1개
  - 데이터 타입: 수치형
  - 행 수: 30개 이상
- **사용 사례**: 나이 분포, 소득 분포, 성적 분포

#### 박스플롯
- **설명**: 데이터 분포와 이상치 확인
- **적합 데이터**: 여러 그룹의 분포 비교
- **데이터 조건**:
  - 열 수: 2개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 20개 이상
- **사용 사례**: 부서별 급여, 제품별 품질

### 4. 특수 분석
특정 목적을 위한 전문화된 차트 유형들입니다.

#### 레이더 차트
- **설명**: 다차원 데이터 비교
- **적합 데이터**: 다차원 특성 비교
- **데이터 조건**:
  - 열 수: 3-8개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 1-5개
- **사용 사례**: 능력 평가, 제품 특성 비교



#### 게이지 차트
- **설명**: KPI, 목표 달성률
- **적합 데이터**: 단일 지표의 현재 상태
- **데이터 조건**:
  - 열 수: 1-2개
  - 데이터 타입: 수치형
  - 행 수: 1개
- **사용 사례**: KPI 모니터링, 진행률 표시

#### 워드클라우드
- **설명**: 텍스트 데이터 빈도 시각화
- **적합 데이터**: 텍스트 데이터의 빈도 분석
- **데이터 조건**:
  - 열 수: 2개
  - 데이터 타입: 텍스트형 + 수치형
  - 행 수: 10-100개
- **사용 사례**: 검색어 분석, 리뷰 키워드

#### 타임라인(공정표)
- **설명**: 프로젝트 일정 및 공정표 관리
- **적합 데이터**: 프로젝트 일정, 이벤트 순서
- **데이터 조건**:
  - 열 수: 3-4개
  - 데이터 타입: 날짜형 + 범주형 + 수치형
  - 행 수: 5-50개
- **사용 사례**: 프로젝트 관리, 이력 관리

### 5. 고급 분석
복잡한 데이터 분석과 다차원 비교를 위한 고급 차트 유형들입니다.

#### 히트맵
- **설명**: 값의 크기를 색으로 표현
- **적합 데이터**: 2차원 매트릭스 데이터
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 범주형 + 범주형 + 수치형
  - 행 수: 5-50개
- **사용 사례**: 상관관계 매트릭스, 월별 지역별 매출

#### 워터폴 차트
- **설명**: 증가·감소 요인별 변화 시각화
- **적합 데이터**: 증감 요인을 분석하는 데이터
- **데이터 조건**:
  - 열 수: 2-3개
  - 데이터 타입: 범주형 + 수치형
  - 행 수: 5-20개
- **사용 사례**: 손익 분석, 예산 대비 실적

#### 콤보 차트
- **설명**: 서로 다른 유형 데이터 동시 비교
- **적합 데이터**: 서로 다른 스케일의 데이터를 함께 표시
- **데이터 조건**:
  - 열 수: 3개 이상
  - 데이터 타입: 혼합형
  - 행 수: 5-30개
- **사용 사례**: 매출과 수익률, 방문자 수와 체류 시간

#### 파넬 차트
- **설명**: 여러 차트를 그리드로 배치
- **적합 데이터**: 여러 차원의 데이터를 동시에 비교
- **데이터 조건**:
  - 열 수: 4개 이상
  - 데이터 타입: 혼합형
  - 행 수: 20개 이상
- **사용 사례**: 다변량 분석, 복합 지표 비교

### 6. 지도 위치 시각화
지리적 위치와 관련된 데이터를 시각화하는 차트 유형입니다.

#### 지도 시각화
- **설명**: 지도에 마커 표시
- **적합 데이터**: 위치가 있는 데이터
- **데이터 조건**:
  - 열: `위도`와 `경도`, 또는 `주소`
  - 주소만 있으면 `VITE_KAKAO_REST_API_KEY`가 필요하다
  - 행 수: 5-100개
- **사용 사례**: 지역별 매출, 인구 밀도
